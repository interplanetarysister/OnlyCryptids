# Interface reference research — 2026-10-22

The owner requested a study of the OnlyFans wrapper and both creator and subscriber experiences before implementation.

The current signed-in interface could not be inspected directly: public fetches of onlyfans.com and blog.onlyfans.com failed. Reference screenshots were retrieved through web image search. These are visual references, not a verified tour of every current feature or any private account. No OnlyFans account was created or accessed.

## Adapted patterns

Subscribers: predictable navigation, creator identity and cover, personal feed, previews, following, saved content, subscription management, and clear cancellation access.

Creators: a persistent publish action, creator onboarding, profile controls, content/draft management, media types, audience selection, and truthful earnings/setup status.

Only Cryptids uses an original charcoal/forest-green identity, cryptid illustration system, discovery by cryptid and content type, explicit fictional sample labels, and no adult-content features. No reference website's code or brand assets were copied. Unverified feature details are not asserted as current OnlyFans behavior.
