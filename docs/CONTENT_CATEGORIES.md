# OnlyCryptids categories and editorial types

The canonical category list is in `base44/functions/cryptid-api/taxonomy.js`, shared by the visitor interface and both cryptid-api entry points. Chupacabra already existed and remains unchanged.

Additional topics: Skinwalkers, Aliens, Ghosts, Alien technologies, Sacred space sightings, Dreamscape. Existing categories Bigfoot, Mothman, Lake monsters, Chupacabra, Jersey Devil, Sea creatures and Unidentified remain.

**Fiction** and **Non-fiction** are separate publishing/browsing genres across posts and forum threads, not competing cryptid topics. Every topic can contain both genres.

- Non-fiction: claimed eyewitness encounters and cited research/commentary. A claim is NOT independent verification. Personal dreams are real reports of subjective experience, not evidence that a supernatural event occurred.
- Fiction: invented stories, illustrations, AI-generated fiction and art. Media described as a real sighting must not be made from invented illustrations.
- Reference media: external licensed images/video indexed by the Media Scout. These are displayed separately from both editorial genres until someone has documented the nature of the source. Reuse licensing alone does NOT establish factual accuracy.
- Existing records without a stored genre receive a compatibility classification from their label. Fiction/Art/AI-Generated => Fiction; Claimed Encounter/Research/Commentary => Non-fiction. No historic records are rewritten automatically.

Do not expose private or precise sacred-site locations or imply that restricted cultural information is public domain. Discuss skinwalker traditions carefully and credit public cultural sources without appropriating confidential ceremonial teachings.

The interface has Fiction, Non-fiction, Encounter reports, Folklore & research and Media references browse lanes; author and forum forms require consistent label/genre pairs. The server enforces the same selection.

The source-backed Worker uses topical categories and a separate Reference media label. The fallback provider Openverse is used when the Commons API rejects automated requests. The media collection does not itself satisfy the first-nonfiction-post live alert.

Changes in GitHub require a production website redeploy to be visible in the Base44-dependent visitor app. Automated source-media hosting on Cloudflare is separate from that frontend deploy.
