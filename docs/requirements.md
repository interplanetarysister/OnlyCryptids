# Only Cryptids — cumulative requirements from this conversation

All three prior builder prompt drafts and protection supplements are treated as cumulative requirements. This file consolidates them for direct implementation; it is not an instruction to spend Base44 builder credits. The original chat remains the source for the verbatim prompts.

## Product and layout

A responsive cryptid media creator-subscription community called Only Cryptids. Familiar creator-platform wrapper: left navigation, central feed, discovery panel, cover/avatar creator profiles, prominent subscription controls; mobile single-column feed and bottom navigation. Original branding/art/code, no OnlyFans affiliation or copied distinctive assets. Dark charcoal, green accents, readable light type, subtle mysterious atmosphere, generous touch targets, scrolling mobile dialogs. No adult-content features.

## Roles

Visitors browse free posts, public profiles and categories. Members follow, subscribe per creator, like, comment, bookmark, report, block, manage privacy/billing/notifications. Creators use the same account and enable creator profiles with photos/cover/bio/interests/pricing, free or paid publishing, drafts, media management, subscriber and accurate earnings information. Administrators moderate, manage categories/featured creators, review payment statuses and IP complaints with server-enforced access.

## Screens and behavior

Home personal feed; Explore search creators/posts/tags/cryptids with format/category filters; Creator profile with free and authorized paid content and subscription terms; Create/Edit Post with title, body, mixed media, text stories, galleries, video/audio, content warnings, accessibility text, category/tags, Free or Subscribers Only, separate approved public preview, optional general location with precise coordinates hidden, draft/preview/publish/edit/delete, progress/limits/recovery; Subscriptions with prices/renewal/status/cancel/access-end; Creator Dashboard with drafts, published posts, subscribers, real earnings; Notifications/preferences; Settings including account deletion; Help/policies; secure Admin area.

Categories include Bigfoot/Sasquatch, Mothman, Nessie/lake monsters, Chupacabra, Jersey Devil, sea creatures, unidentified encounters and other owner-managed categories. Labels: Claimed Encounter, Fiction, Art, Research/Commentary, AI-Generated. Claims are unverified.

## Payments

Monthly per-creator subscriptions using an appropriately supported marketplace provider and payouts. Secure server secrets, verified server payment events, renewal/failure/refund/cancel handling, idempotent webhooks, configurable disclosed platform/processor fees, no fabricated payment/earnings/access, explicitly separated demos, clear setup states. No optional metered services activated without owner approval.

## Data and security

Persistent users, creators, posts, media, categories/tags, follows, subscriptions, payments, likes, comments, bookmarks, notifications, reports, copyright complaints, policy acceptances and audit records. Server permission checks, ownership enforcement, subscription entitlements, expiration checks, private originals and short-lived access, separate previews, no full paid content or original URIs in public responses, upload validation/safe rendering, duplicate prevention, restricted secrets, sensitive-action audit logs, admin MFA where supported, backups/recovery.

## Community

Report/block and creator comment moderation. Rules against harassment, copyright infringement, dangerous trespassing, animal harm, impersonation, private-location disclosure. Clear labels on original/appropriately licensed fictional sample Bigfoot journal, Mothman art gallery, lake encounter, nighttime audio investigation, expedition update. No invented real users/subscribers/earnings/evidence.

## Intellectual property and owner protection

All protection requirements in legal-protection-plan.md are mandatory: original assets and brand clearance; owner records, source export, licensing inventory, contribution history, confidentiality and assignment drafts, legitimate copyright notices, retained creator ownership and narrow licenses, separately consented AI/advertising/relicensing, protected originals, optional watermarks, provenance hashes, GPS stripping, accurate copyright complaint/counter-notice/repeat-infringer workflow and owner-reviewed policies. No registration or exclusive-idea guarantee.

## Completion standard

Connected useful interactions with loading/empty/error/success states, original styling and mobile layouts. Honest handoff distinguishing working features, external configuration, unresolved legal owner details, review/filings, and source access. Checkpoints after direct Base44 edits. First implement the functional product foundation, then finish the protection supplements. Do not conflate a local design preview with a deployed Base44 app.
